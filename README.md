# EasyStock 📦

Sistema simples de controle de estoque desenvolvido em linguagem C.

## Descrição

O EasyStock é um programa criado para auxiliar no gerenciamento de produtos de um pequeno estoque. Com ele, é possível cadastrar, consultar, listar, atualizar e remover produtos de forma rápida e prática através de um menu no terminal.

Este projeto foi desenvolvido com o objetivo de aplicar conceitos fundamentais da programação em C, como:

- Estruturas (struct)
- Vetores
- Funções
- Laços de repetição
- Condições
- Manipulação de arquivos
- Entrada e saída de dados

## Funcionalidades

✅ Cadastrar produtos

✅ Listar todos os produtos cadastrados

✅ Consultar um produto pelo nome

✅ Atualizar quantidade e preço de um produto

✅ Remover produtos do estoque

✅ Salvar dados em arquivo para uso futuro

## Estrutura do Produto

Cada produto possui:

- Nome
- Quantidade
- Preço unitário

## Como Executar

### Compilar

```bash
gcc easystock.c -o easystock
```

### Executar

```bash
./easystock
```

No Windows:

```bash
easystock.exe
```
